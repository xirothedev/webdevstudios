# Vue 3 Resources

## Knowledge

- [Docs: Reactivity Fundamentals (Vue official)](https://vuejs.org/guide/essentials/reactivity-fundamentals)
  Nguồn chính cho ref/computed/watch/template unwrapping. Dùng cho: mọi thứ về reactivity cơ bản. (Bản markdown cho máy đọc: thêm `.md` vào URL)
- [Docs: Reactivity in Depth (Vue official)](https://vuejs.org/guide/extras/reactivity-in-depth)
  Proxy-based tracking, effect scope, so sánh với cơ chế re-render của React. Dùng cho: giải thích "vì sao không cần deps array".
- [Docs: Composition API FAQ (Vue official)](https://vuejs.org/guide/extras/composition-api-faq)
  Lý do thiết kế setup(), so sánh trực tiếp với React hooks. Dùng cho: câu hỏi "sao không giống React".
- [Docs: Component Basics (Vue official)](https://vuejs.org/guide/essentials/component-basics)
  SFC, props, emits, slots. Dùng cho: đọc hiểu `apps/web-vue/src/components`.
- [Repo local: apps/web-vue (code thật do agent port từ apps/web)](../../apps/web-vue)
  Mọi pattern đã dùng thật: vee-validate forms, vue-query composables, router guards. Dùng cho: ví dụ "thật" thay vì ví dụ toy.
