Bảng mapping core

React Vue Khác nhau cần nhớ
useState + setter immutable const x = ref(0), sửa bằng x.value++ Vue mutate trực tiếp; không có "state cũ bị đóng băng"
useMemo(fn, [deps]) const y = computed(() => x.value * 2) Không cần deps array — Vue tự track qua .value
useEffect(fn, [dep]) watch(x, fn) / watchEffect(fn) watchEffect tự gom dep; tự dọn khi unmount
Component re-run mỗi render Setup chỉ chạy 1 lần Vue cập nhật DOM qua effect nhỏ, không chạy lại function
{cond && <X/>} <X v-if="cond"/> Directive trong template, không phải JS expression
list.map(i => <X key/>) <X v-for="(i, n) in list" :key="i.id"/> v-for đặt trên chính element
value={v} onChange={e} v-model="x" Two-way binding một phát, khỏi viết handler
props + callback prop defineProps / defineEmits Macro trong <script setup>
children <slot> Named/slot props cho API giàu hơn
react-hook-form vee-validate (useForm/useField) + zod toTypedSchema ≈ zodResolver
@tanstack/react-query @tanstack/vue-query Params là ref/getter, đọc bằng toValue()
next/link <RouterLink to="..."/> vue-router, history mode

Vòng đời (ít khi cần — setup ≈ mount)

React Vue
effect chạy khi mount Code trực tiếp trong setup, hoặc onMounted
cleanup return onUnmounted, hoặc watch tự stop

Bẫy cho người từ React sang

  • Quên .value trong script → không lỗi, chỉ không reactive. Template tự unwrap, script thì không.
  • Phá reactive: const { x } = props hoặc gán obj = {...} mới → mất track. Dùng toRefs, mutate từng field.
  • Đừng bọc mọi thứ trong state — biến không render thì là biến thường.
