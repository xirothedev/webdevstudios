## Agent skills

### Issue tracker

Issues live in GitHub Issues, managed via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five default labels (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Multi-context layout: `CONTEXT-MAP.md` at the root, one `CONTEXT.md` + `docs/adr/` per app. See `docs/agents/domain.md`.

### Packages

Packages are deep modules — see [packages/README.md](./packages/README.md) before adding or importing one.
